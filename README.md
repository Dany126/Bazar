# 🛍️ Bazar

**Bazar** is a modern e-commerce mobile application built with **Flutter and Dart**, designed to provide users with a smooth and intuitive online shopping experience.

The application focuses on clean UI, reusable components, scalable architecture, and a seamless shopping flow from browsing products to completing orders.

## ✨ Features

* 🏠 Modern Home Screen
* 🔎 Product Search
* 🗂️ Product Categories
* 📦 Product Details
* 🛒 Shopping Cart
* ❤️ Favorites
* 🎟️ Coupon Support
* 💳 Checkout Flow
* 📋 Order Management
* 🔔 Notifications
* 👤 User Profile
* 📱 Responsive UI

## 🛠️ Technologies

* **Flutter**
* **Dart**
* **BLoC / Cubit**
* **Clean Architecture**
* **REST APIs**
* **Dio**
* **Firebase**
* **Local Storage**
* **Responsive & Adaptive UI**

## 🏗️ Architecture

The project follows a structured and scalable architecture that separates application responsibilities into different layers:

```text
lib/
├── core/
│   ├── services/
│   ├── utils/
│   ├── widgets/
│   └── ...
│
├── features/
│   ├── auth/
│   ├── home/
│   ├── product/
│   ├── cart/
│   ├── order/
│   ├── notification/
│   └── profile/
│
└── main.dart
```

This structure helps keep the application **maintainable, testable, and easy to extend**.

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

* Flutter SDK
* Dart SDK
* Android Studio or VS Code
* Git

### Installation

Clone the repository:

```bash
git clone https://github.com/Dany126/Bazar.git
```

Navigate to the project:

```bash
cd Bazar
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```
